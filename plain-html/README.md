# Standalone HTML Portfolio

This folder is the plain HTML, CSS, and JavaScript version of the portfolio. It is independent of the React/Vite app in the parent folder and can be opened directly by opening `index.html` in a browser.

## Files

- `index.html` contains the page structure.
- `styles.css` contains responsive layout and visual styles.
- `data.js` contains the portfolio content.
- `app.js` renders the data and provides the mobile menu and scroll reveals.
- `assets/` contains the favicon and downloadable resume PDF.

Edit profile details, project descriptions, experience, or skills in `data.js`.
